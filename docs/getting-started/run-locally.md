# Run Locally

## Prerequisites

* [Bun](https://bun.sh)
* A Gemini API key

## Setup

{% code title="Terminal" %}
```bash
# 1. Install dependencies
bun install

# 2. Set up environment variables
cp .env.example .env
# then fill in your keys in .env

# 3. Start the app
bun run dev
```
{% endcode %}
