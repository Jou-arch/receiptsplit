# ReceiptSplit

ReceiptSplit is a consumer Web3 app that makes splitting everyday bills easy (eating out, movies, hangouts) using AI receipt parsing and gasless on-chain settlement on BNB Chain.

Built for **Indonesia Web3 Hackathon 2026** · Consumer Apps Track · Team **Tovix**

{% hint style="success" %}
🔗 **Live app:** [https://receiptsplit-1.ai.studio](https://receiptsplit-1.ai.studio)

No installation needed. See [How to Try](getting-started/how-to-try.md).
{% endhint %}

## At a glance

| | |
| --- | --- |
| **AI parsing** | Gemini Vision API reads items, prices, tax and service charge |
| **Fair split** | Tax and service fees split proportionally per person |
| **Gasless payment** | ERC-4337 smart wallet, gas sponsored by a Paymaster (0 BNB needed) |
| **Transparent settlement** | Every payment is an on-chain transfer, verifiable on BscScan |
